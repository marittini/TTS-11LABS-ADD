ElevenLabs TTS Message Controls 4.3.3

설치
기존 ElevenLabs TTS Message Controls 확장을 이 파일로 교체한 후 ME를 새로고침합니다.
이전 버전과 동시에 실행하지 마세요.
업데이트 첫 실행 시 이 확장이 생성한 ElevenLabs TTS 4.1 / 이름의 전역 정규식만 정리합니다. 사용자 제작 정규식은 수정하지 않습니다.

수정
- Game / RP / Convo 외 화면에서 대사 처리 및 TTS 요청 가로채기 중단.
- 생성 지침은 현재 열린 지원 모드의 채팅 요청에만 추가. 명시적 에이전트 요청은 제외.
- 번역 보호는 현재 방에서 확인된 AI 출력에만 적용. 사용자 입력, JSON 객체/배열, 에이전트 요청은 원본 그대로 전달.
- 대괄호 전체를 감정 태그로 취급하지 않고 지정된 음성 태그만 숨김.
- [사진: …] 등 일반 대괄호 표현 보존.
- 음성 태그 뒤 공백/탭까지 숨김. 줄바꿈은 보존.
- 사용자 메시지와 입력창에는 화면 숨김을 적용하지 않음.
- 원문, 저장 메시지, 실제 TTS 입력의 감정 태그는 보존.
- 범위 제한이 불가능한 서버 저장 전역 정규식을 새로 만들지 않음.

검증
JavaScript 문법 검사, 원본 코드의 음성 태그/공백 처리, 사용자 입력 우회, 지원 모드 판정, 생성 요청 범위, 짧은/긴 JSON 우회, 번역 보호/복원, 보호 표식 누락 시 자동 재요청 없음 확인.
실제 ME 화면, 설치된 Gacha Forge/Noodle/Slurp 실행, ElevenLabs 유료 음성 생성은 테스트하지 않음.

표시 처리 기준
새 음성 태그를 무제한으로 숨기지 않습니다. 알려진 영어/한국어 감정·발성 태그만 숨기며, 목록에 없는 대괄호 표현은 표시합니다.
번역 원문을 현재 방의 AI 출력으로 확인할 수 없으면 TTS 번역 보호를 적용하지 않습니다.
